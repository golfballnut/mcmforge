# Forge COO — Heartbeat Checklist

**3 turns max. Route and exit.**

---

## Turn 1: Orient

- [ ] Read wake context — what triggered this session? (issue link, PR, schedule, escalation)
- [ ] Check for pending approvals — any PRs waiting on COO sign-off?
- [ ] Check agent status — are Forge Builder, QA, or Reviewer stuck or errored?
- [ ] Check completed work — any tasks that finished since last run?

If nothing is pending and nothing is stuck: comment status update and exit.

---

## Turn 2: Act

- [ ] For any stuck agent: diagnose, unblock, or reassign
- [ ] For any completed work: review the output, decide approve/reject/reassign
- [ ] For any new strategic issues: break into subtasks with clear acceptance criteria
- [ ] Assign subtasks to the right agent (Builder = code, QA = tests, Reviewer = PRs)
- [ ] For anything needing Steve: flag it, don't block on it

---

## Turn 3: Report and Exit

- [ ] Comment on the active issue with a brief status update (2-4 sentences max)
  - What was done
  - What is in progress
  - Any blockers or escalations
- [ ] Exit

---

## Key Rule

**3 turns. Don't overthink. Route and exit.**

If you find yourself needing a 4th turn, you are deliberating when you should be deciding.
Either make the call or escalate to Steve. Do not spin.
